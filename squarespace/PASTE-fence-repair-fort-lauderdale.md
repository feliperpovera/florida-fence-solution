# Paste: Fence Repair in Fort Lauderdale, FL

Generated by `python3 squarespace/cities.py` (which also runs services.py and pages.py).
Page data lives in the `L` list in `squarespace/services.py`; metadata in `squarespace/services/meta.json`.

## 1. Create the new page

1. Squarespace > Pages > **+** > Blank page. Create it in the same section as `/fence-repair` (usually **Not Linked**).
2. Page title (nav): `Fence Repair Fort Lauderdale`
3. Settings > General > URL slug: `fence-repair-fort-lauderdale-fl`
4. Settings > SEO:
   - SEO title: `Fence Repair in Fort Lauderdale, FL | Florida Fence Solution`
   - SEO description: `Fence repair in Fort Lauderdale, FL: leaning posts, broken panels, sagging gates and storm damage on wood, PVC, aluminum & chain-link. Call (754) 208-9268.`
5. Delete the default section content, add one **Code** block, set it to HTML, and paste the full contents of
   `squarespace/services/fence-repair-fort-lauderdale-fl.html`. Turn "Display source" off. Save.
6. Publish (enable the page).

## 2. JSON-LD check

The block ends with two `<script type="application/ld+json">` tags (Service + FAQPage). After publishing,
run https://search.google.com/test/rich-results on the live URL.
- If both are detected: done.
- If they are missing (the plan strips scripts from code blocks): copy those two `<script>` tags from the end of the
  file into Page Settings > Advanced > **Page Header Code Injection**, and remove them from the code block so they are not duplicated.

## 3. Re-paste two existing blocks (they now link to the new page)

Replace the whole code block content on each page with the regenerated file:

| Live page | File to paste |
|---|---|
| `/fence-repair` | `squarespace/services/fence-repair.html` |

The other regenerated files only gained two CSS rules (underlined inline links, `h3` spacing in `.prose`) that do
not change how those pages look. Re-pasting them is optional.

## 4. After publishing

- Open the new URL on mobile and desktop; check the hero, gallery and FAQ.
- Google Search Console > URL Inspection > the new URL > Request indexing. Do the same for `/fence-repair` and `/fence-company-fort-lauderdale-fl`.
- Squarespace adds the page to `/sitemap.xml` automatically once it is enabled.
